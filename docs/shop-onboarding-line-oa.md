# เชื่อม LINE OA ของร้านกับ ClipperQ

คู่มือสำหรับเจ้าของร้านตัดผม (ไม่ต้องเป็นสายไอที)  
**หลักการ:** ร้านใช้ **LINE OA ของร้านเอง** และโควตา push ฟรีประมาณ **300 ข้อความ/เดือน** ของ OA นั้น  
โทเคนโกลบอลของ ClipperQ ใช้กับร้าน demo/ทดสอบเท่านั้น — ร้านจริงต้องเชื่อมคีย์ของตัวเอง

**ห้าม** ส่ง Channel Secret / Access Token ในแชท LINE หรืออีเมล — กรอก**เฉพาะในแอป ClipperQ** เท่านั้น

หน้าจอในแอป: **แอดมิน → ตั้งค่า → 「LINE และการแจ้งเตือน」→ 「เชื่อม LINE OA」**  
เส้นทาง: `/{slug}/admin/settings/line`

---

## (A) เปิด Messaging API + วางคีย์ใน ClipperQ

1. เปิด **LINE Official Account Manager** ของ OA ร้านคุณ  
2. ไป **ตั้งค่า → Messaging API** แล้วเปิดใช้ Messaging API  
3. สร้างหรือเลือก **Provider** ชื่อตามร้าน (ข้อความในแอป: 「เลือก provider ชื่อร้านคุณ (ย้ายทีหลังไม่ได้)」)  
4. เปิด **LINE Developers** → เข้า Messaging API channel ของร้านนั้น  
5. คัดลอกค่าต่อไปนี้ (อย่าส่งให้ใครในแชท):  
   - **Channel ID**  
   - **Channel secret** (แท็บ Basic settings)  
   - **Channel access token (long-lived)** — กด Issue ถ้ายังไม่มี  
6. ใน ClipperQ เปิดหน้า **「เชื่อม LINE OA ของร้าน」** → กด **「ไม่อยากเชิญเรา? กรอกคีย์เอง >」**  
7. วางลงช่องในแอป (ชื่อช่องตาม UI):  
   - `Channel ID`  
   - `Channel Secret`  
   - `Channel access token (long-lived)`  
8. กด **「ทดสอบการเชื่อมต่อ」** (ระบบเก็บแบบเข้ารหัส · แสดงเฉพาะ 4 ตัวท้ายหลังบันทึก)

### ตรวจว่าผ่านแล้ว
- [ ] หน้าแอปขึ้นสถานะประมาณ **「เชื่อมต่อแล้ว」** / **「LINE OA ของร้าน」**  
- [ ] มีชื่อบอทหรือ Basic ID ของ OA แสดงใต้หัวข้อ  
- [ ] เจ้าของร้านได้รับข้อความทดสอบใน LINE จาก OA ของร้าน (ถ้าล็อกอินแอดมินด้วย LINE ที่ผูกแล้ว)

## (B) Webhook + ปิดตอบกลับอัตโนมัติ

ข้อความในแอป (ขั้นที่ 2–3):

- **「วาง Webhook URL」** — 「หน้าเดียวกัน → ช่อง Webhook URL → บันทึก」  
- **「ปิดข้อความตอบกลับอัตโนมัติ」** — 「ตั้งค่าการตอบกลับ: เปิด Webhook · ปิดตอบกลับอัตโนมัติ」

1. ในหน้าเชื่อม LINE OA ของ ClipperQ (มุมมองเช็คลิสต์) กด **「คัดลอก」** ที่ช่อง Webhook URL  
2. URL มีรูปแบบ:  
   `https://<โดเมนแอป>/api/line/webhook/<shopId>`  
   โดย `<shopId>` คือ **รหัสร้าน (UUID)** ไม่ใช่ slug — คัดลอกจากแอปอย่างเดียว อย่าพิมพ์เอง  
3. วางใน LINE Developers / OA Manager ช่อง **Webhook URL** → บันทึก  
4. เปิด **Use webhook** (ใช้ Webhook)  
5. ไปตั้งค่าการตอบกลับ: **เปิด Webhook** และ **ปิดตอบกลับอัตโนมัติ** (และปิด greeting อัตโนมัติถ้ามี ที่รบกวนแชทจอง)

### ตรวจว่าผ่านแล้ว
- [ ] ใน Console เปิด Use webhook แล้ว  
- [ ] ตอบกลับอัตโนมัติ / ทักทายอัตโนมัติปิดแล้ว  
- [ ] กด **「ทดสอบการเชื่อมต่อ」** อีกรอบแล้วยัง **「เชื่อมต่อแล้ว」**

[ภาพหน้าจอ: ช่อง Webhook URL ใน ClipperQ พร้อมปุ่มคัดลอก]  
[ภาพหน้าจอ: Use webhook เปิด + ปิด auto-reply ใน LINE]

> หมายเหตุจากโค้ด: รายการเช็ค「ปิดตอบกลับอัตโนมัติแล้ว」ในผลการทดสอบถูกตั้งว่าผ่านโดยอัตโนมัติ — **ยังไม่มีการเรียก LINE API ยืนยัน**ว่าคุณปิดจริง ต้องเช็คด้วยตาใน Console

## (C) Rich Menu — ปุ่มเปิดหน้าจอง

ClipperQ **ไม่บังคับ**เทมเพลต Rich Menu — ร้านตั้งเองใน **LINE Official Account Manager**

1. ในแอดมิน ClipperQ คัดลอก **ลิงก์จอง** ของร้าน (เช่นจากบอร์ด / 「คัดลอกลิงก์จอง」 / 「หน้าจองลูกค้า」)  
2. ลิงก์ที่ระบบสร้างให้มีรูปแบบ (จากโค้ด `buildShopLiffUrl` / `buildShopCustomerUrl`):  
   - ถ้ามี LIFF: `https://liff.line.me/<LIFF_ID>/<slug>`  
   - หรือเว็บ: `https://<โดเมน>/<slug>`  
   และ「คิวของฉัน」: ต่อท้าย `/bookings`  
3. ใน OA Manager สร้าง Rich Menu → ปุ่มอย่างน้อย:  
   - **จองคิว** → วางลิงก์จองด้านบน  
   - **คิวของฉัน** → วางลิงก์ `…/<slug>/bookings`  
4. (ทางเลือก) ดาวน์โหลด PNG ตัวอย่างจากคู่มือเว็บ `/guide` ส่วน「Rich Menu สำหรับร้าน」หรือไฟล์ใน `public/rich-menu/`

### ตรวจว่าผ่านแล้ว
- [ ] ในแชท OA กดปุ่มจองแล้วเปิดหน้าจองของ **ร้านคุณ** (ชื่อร้านถูก)  
- [ ] กด「คิวของฉัน」แล้วเห็นหน้าคิวของลูกค้า

[ภาพหน้าจอ: คัดลอกลิงก์จองในแอดมิน]  
[ภาพหน้าจอ: Rich Menu ใน OA Manager ที่ใส่ลิงก์แล้ว]

> **UNKNOWN:** แอปยัง**ไม่มี**หน้าตั้ง LIFF / Login channel **แยกร้าน** (`login_channel_id`, `liff_id` ในตารางมี แต่ UI ไม่ได้กรอก) — ตอนนี้ใช้ LIFF ของแพลตฟอร์ม ClipperQ + path เป็น slug ร้าน

## (D) เช็คลิสต์ทดสอบหลังเชื่อม

1. ในหน้า **「เชื่อม LINE OA」** กด **「ทดสอบการเชื่อมต่อ」** (หรือ **「ทดสอบอีกครั้ง」**)  
2. สถานะต้องเป็น **「เชื่อมต่อแล้ว」**  
3. เจ้าของได้รับข้อความประมาณ: `ClipperQ: ทดสอบการเชื่อมต่อ LINE OA ของร้านสำเร็จ (…)` ในแชท **OA ของร้าน**  
4. ให้ลูกค้า (หรือมือสอง) จองคิวผ่านลิงก์จอง / Rich Menu  
5. ลูกค้าต้องได้ข้อความยืนยันจาก **OA ของร้าน** (ไม่ใช่แค่ OA demo ของแพลตฟอร์ม)  
6. (แนะนำ) ดูโควตาที่ **「ดูโควตา push」** → `/admin/settings/line/quota`

### ตรวจว่าผ่านแล้ว
- [ ] ทดสอบการเชื่อมต่อผ่าน  
- [ ] ได้ข้อความทดสอบใน LINE  
- [ ] จองจริงแล้วลูกค้าได้ยืนยันจาก OA ร้าน  
- [ ] โควตายังไม่เต็ม (แพ็กเกจฟรี ~300/เดือน)

---

## (E) ให้ ClipperQ ตั้งให้

ถ้าไม่อยากกรอกคีย์เอง:

1. ในเช็คลิสต์แอป ขั้น **「เชิญ ClipperQ เป็น Admin」** — กด **「คัดลอก」** อีเมลที่แสดง (รูปแบบ `setup+<shopId>@…`)  
2. ใน LINE Developers → provider ของร้าน → **Roles → Invite by email** เชิญอีเมลนั้นเป็น **Admin**  
3. แจ้งทีม ClipperQ ว่าเชิญแล้ว (ส่ง**แค่**ชื่อร้าน/slug — **ห้าม**ส่ง secret)  
4. การเชิญ Admin หมายความว่าคุณ**ยินยอม**ให้ทีมช่วยตั้ง Messaging API / webhook / ตรวจการเชื่อมต่อในขอบเขตที่จำเป็นเท่านั้น — คุณยังเป็นเจ้าของ OA และโควตา push ของร้าน

[ภาพหน้าจอ: ขั้นเชิญ Admin + ช่องอีเมลใน ClipperQ]

## ติดปัญหา?

| อาการ | สาเหตุที่พบบ่อย (จากโค้ด) | ทำอย่างไร |
| --- | --- | --- |
| กรอกไม่ครบ / ทดสอบไม่ผ่านเรื่องคีย์ | ขาด Channel ID / Secret / Token | กรอกครบทั้งสามช่องแล้วกดทดสอบอีกครั้ง (`MISSING_KEYS`) |
| 「Access token ใช้ไม่ได้ หรือหมดอายุ」 | Token ผิดหรือหมดอายุ | Issue token ใหม่จากแท็บ Messaging API แล้ววางใหม่ (`TOKEN_INVALID`) |
| 「Channel Secret ไม่ตรง…」 | Secret คนละ channel กับ Channel ID | คัดลอก Channel secret จาก Basic settings ของ **channel เดียวกัน** (`SIGNATURE_MISMATCH`) |
| เซิร์ฟเวอร์ตอบประมาณตั้งค่าไม่ครบ / เก็บคีย์ไม่ได้ | ไม่มี `APP_ENCRYPTION_KEY` บนเซิร์ฟเวอร์ | ติดต่อทีม ClipperQ ตั้งค่า (`ENCRYPTION_KEY_MISSING` / ข้อความ fix ในแอป) — **เจ้าของร้านแก้เองไม่ได้** |
| Webhook ตอบ 404 / `channel_not_configured` | ยังไม่มี secret ของร้านในระบบ | บันทึกคีย์ในแอปให้สำเร็จก่อน แล้วค่อยเปิด webhook |
| ส่งข้อความไม่ไป / โควตาเต็ม | ใช้ครบงบประมาณ push ของเดือน (ค่าเริ่มต้น 300) | ดูหน้าโควตา · รอรีเซ็ตรอบเดือน หรืออัปเกรดแพ็กเกจ LINE ของร้านเอง |
| ลูกค้าไม่ได้ข้อความยืนยัน | OA ยังไม่เชื่อม / ลูกค้ายังไม่เป็นเพื่อน OA / ปิด「ยืนยันจอง」ในตั้งค่า | เชื่อม OA ให้ `verified` · ให้ลูกค้าแอดเพื่อน OA · เช็คสวิตช์ยืนยันจองในตั้งค่า |
| แชท OA ตอบข้อความแปลก ๆ เอง | ยังเปิดตอบกลับอัตโนมัติ | ปิดตามขั้น (B) |

## สคริปต์วิดีโอสอน 2–3 นาที

| ฉาก | หน้าจอที่ถ่าย | ประโยคพูด (ไทย) |
| --- | --- | --- |
| 1 | หน้าแอดมิน ClipperQ → ตั้งค่า → 「LINE และการแจ้งเตือน」 | 「วันนี้เราจะเชื่อม LINE OA ของร้านกับ ClipperQ ใช้เวลาไม่กี่นาที」 |
| 2 | เปิด「เชื่อม LINE OA」+ เช็คลิสต์ 4 ขั้น | 「เข้าเมนูเชื่อม LINE OA แล้วทำตามเช็คลิสต์」 |
| 3 | OA Manager → Messaging API | 「เปิด Messaging API ของ OA ร้าน แล้วเลือก provider ชื่อร้าน」 |
| 4 | LINE Developers → คัดลอก ID / secret / token | 「คัดลอก Channel ID, Secret และ Access Token แบบ long-lived — อย่าส่งในแชท」 |
| 5 | ฟอร์มคีย์ใน ClipperQ + กด「ทดสอบการเชื่อมต่อ」 | 「วางใน ClipperQ แล้วกดทดสอบการเชื่อมต่อ จนขึ้นเชื่อมต่อแล้ว」 |
| 6 | คัดลอก Webhook URL + วางใน LINE + เปิด Use webhook | 「คัดลอก Webhook จากแอป วางใน LINE แล้วเปิดใช้ Webhook」 |
| 7 | ตั้งค่าการตอบกลับ — ปิดอัตโนมัติ | 「เปิด Webhook และปิดตอบกลับอัตโนมัติ เพื่อไม่ให้แทรกแซงข้อความจอง」 |
| 8 | คัดลอกลิงก์จอง + ใส่ Rich Menu | 「คัดลอกลิงก์จองจากแอดมิน ไปวางปุ่มจองคิวใน Rich Menu」 |
| 9 | จองทดสอบ + ข้อความยืนยันจาก OA ร้าน | 「ลองจองคิวหนึ่งครั้ง ลูกค้าต้องได้ข้อความจาก OA ของร้านคุณ」 |
| 10 | (ทางเลือก) ขั้นเชิญ Admin | 「ถ้าต้องการให้ทีมช่วย เชิญอีเมลที่แอปแสดงเป็น Admin ได้ — ไม่ต้องส่งรหัสลับ」 |
