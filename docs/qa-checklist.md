## 7) Web Push (เจ้าของ / ช่าง)

- [ ] aC — อนุญาตแจ้งเตือนได้ · ส่งทดสอบแล้วเห็นบนเครื่อง
- [ ] aL — บันทึกพฤติกรรมจริง (รองรับ/ไม่รองรับตามเบราว์เซอร์ LINE) · คิวยังใช้ได้ปกติ
